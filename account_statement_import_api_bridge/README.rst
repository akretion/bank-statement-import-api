========================
Odoo-BridgeAPI connector
========================

This is the connector between Odoo and `BridgeAPI <https://www.bridgeapi.io/>`_, a bank aggregator. BridgeAPI supports a long list of european banks, taking advantage of DSP2 to automate the download of bank statement lines from banks. This module implements the `API of BridgeAPI <https://docs.bridgeapi.io/reference/get-started>`_ for bank account aggregation.
