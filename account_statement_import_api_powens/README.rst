=====================
Odoo-Powens connector
=====================

This is the connector between Odoo and `Powens <https://www.powens.com/>`_, a bank aggregator. Powens takes advantage of DSP2 to automate the download of bank statement lines from banks. This module implements the `API of Powens <https://docs.powens.com/api-reference>`_ for bank account aggregation.

At this time, the module is marked as uninstallable, because it is not up-to-date with the latest evolutions that took place in the base module **account_statement_import_api**. So, if you want to use it, the module would need some additionnal development.
